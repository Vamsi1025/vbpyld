# VBYPLD Registration Website

Django website for the Viksit Bharat Young Political Leaders' Dialogue registration campaign.

## Run Locally

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe manage.py runserver
```

Open `http://127.0.0.1:8000/`.

The registration button redirects to the official Google Form:
`https://forms.gle/t2KvThYJqQcsGkWK6`
